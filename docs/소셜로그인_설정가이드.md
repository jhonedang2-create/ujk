# 카카오 · 네이버 간편로그인 설정 가이드

**대상 사이트** : 보령대천우정김 자사몰 (`ujk` 프로젝트)
**소요 시간** : 약 5분
**필요한 것** : 카카오계정 1개, 네이버계정 1개 (회사 대표 계정 권장)

---

## 이 작업이 왜 필요한가요

현재 자사몰 로그인 화면에 아래 안내문이 떠 있습니다.

> 소셜 로그인이 아직 설정되지 않았습니다.
> `.env` 에 네이버·카카오 키를 넣으면 간편 로그인 버튼이 표시됩니다.

카카오와 네이버에서 **앱 키 4개**를 발급받아 서버에 넣어야
"카카오로 시작하기 / 네이버로 시작하기" 버튼이 나타납니다.
발급은 **무료**이고, 심사나 승인 없이 즉시 발급됩니다.

> **중요** — 이 앱은 반드시 **회사(보령대천우정김) 명의 계정**으로 등록해 주세요.
> 개인 계정으로 등록하면 나중에 사업자 인증이나 서비스 검수 단계에서
> 명의를 옮기기가 번거로워집니다.

---

## 최종적으로 받아야 할 값 4개

작업을 마치면 아래 4개를 담당자에게 전달해 주시면 됩니다.
아래 표를 그대로 복사해서 값을 채워 보내주셔도 됩니다.

```
카카오 REST API 키    :
카카오 Client Secret  :
네이버 Client ID      :
네이버 Client Secret  :
```

> 이 값들은 **비밀번호와 같은 등급의 정보**입니다.
> 단톡방이나 공개된 곳에 올리지 마시고, 담당자에게 개별로 전달해 주세요.

---

# 1단계 — 카카오 (약 3분)

## 1-1. 개발자 사이트 로그인

https://developers.kakao.com 접속 → 우측 상단 **로그인** (평소 쓰시는 카카오계정)

## 1-2. 애플리케이션 만들기

**내 애플리케이션** → **애플리케이션 추가하기**

| 항목 | 입력값 |
|---|---|
| 앱 이름 | `대천우정김` |
| 회사명 | `보령대천우정김` |
| 카테고리 | 쇼핑 |

**저장**을 누릅니다.

## 1-3. REST API 키 복사 ⭐ 1번 값

만들어진 앱을 클릭 → 좌측 메뉴 **앱 키**

여러 개의 키가 보입니다. 그중 **REST API 키**를 복사해 두세요.

> 네이티브 앱 키 / JavaScript 키 / Admin 키가 아니라
> 반드시 **REST API 키**입니다. 헷갈리기 쉬우니 한 번 더 확인해 주세요.

## 1-4. 카카오 로그인 켜기

좌측 메뉴 **카카오 로그인**

1. 상단 **활성화 설정**을 **ON** 으로 변경
2. 아래 **Redirect URI** → **Redirect URI 등록** 클릭
3. 아래 주소를 **그대로** 붙여넣기 (오타 주의)

```
http://localhost:3000/api/auth/callback/kakao
```

4. **저장**

## 1-5. Client Secret 발급 ⭐ 2번 값

좌측 메뉴 **카카오 로그인** → **보안**

1. **Client Secret** 항목의 **코드 생성** 클릭
2. 생성된 코드를 복사해 두세요
3. 바로 아래 **활성화 상태**를 **사용함** 으로 변경 → **저장**

> ⚠️ **가장 많이 놓치는 부분입니다.**
> 코드만 만들고 '사용안함' 상태로 두면, 로그인 버튼을 눌렀을 때
> 인증 실패 에러가 납니다. 반드시 **사용함**까지 확인해 주세요.

## 1-6. 동의항목 설정

좌측 메뉴 **카카오 로그인** → **동의항목**

| 항목 | 설정 |
|---|---|
| 닉네임 | **필수 동의** |
| 프로필 사진 | 선택 동의 |
| 카카오계정(이메일) | 지금은 설정하지 않아도 됩니다 |

> 이메일 수집은 카카오 측 별도 심사(비즈앱 전환)가 필요합니다.
> 이메일이 없어도 회원가입·로그인이 정상 동작하도록 만들어져 있으니
> 지금 단계에서는 건너뛰셔도 됩니다.

**카카오 완료.** 1번·2번 값을 잘 보관해 주세요.

---

# 2단계 — 네이버 (약 2분)

## 2-1. 애플리케이션 등록

https://developers.naver.com/apps/#/register 접속 → 네이버 로그인

## 2-2. 정보 입력

| 항목 | 입력값 |
|---|---|
| 애플리케이션 이름 | `대천우정김` |
| 사용 API | **네이버 로그인** 선택 |

**네이버 로그인**을 고르면 아래에 제공 정보 선택이 나타납니다.
다음 항목을 체크해 주세요.

- 회원이름
- 이메일
- 휴대전화번호

## 2-3. 서비스 환경 설정

**로그인 오픈 API 서비스 환경** → **PC 웹** 추가

| 항목 | 입력값 |
|---|---|
| 서비스 URL | `http://localhost:3000` |
| Callback URL | `http://localhost:3000/api/auth/callback/naver` |

## 2-4. 키 복사 ⭐ 3번 · 4번 값

**등록하기**를 누르면 다음 화면에 키가 표시됩니다.

- **Client ID** 복사 ⭐ 3번 값
- **Client Secret** 복사 ⭐ 4번 값

> Client Secret은 **보기** 버튼을 눌러야 보이는 경우가 있습니다.

**네이버 완료.**

---

# 3단계 — 담당자에게 전달

아래 형식 그대로 채워서 전달해 주세요.

```
카카오 REST API 키    : 여기에 붙여넣기
카카오 Client Secret  : 여기에 붙여넣기
네이버 Client ID      : 여기에 붙여넣기
네이버 Client Secret  : 여기에 붙여넣기
```

담당자가 서버 설정 파일(`.env`)에 넣고 서버를 재시작하면
로그인 화면의 노란 안내문이 사라지고
**카카오로 시작하기 / 네이버로 시작하기** 버튼이 나타납니다.

---

# 참고 — 나중에 실제 도메인으로 오픈할 때

지금 등록한 `http://localhost:3000` 은 **개발용 주소**입니다.
실제 도메인(예: `https://ujgim.co.kr`)으로 사이트를 여는 시점에,
카카오와 네이버 양쪽에 아래 주소를 **추가로** 등록해야 합니다.

**카카오** — 카카오 로그인 → Redirect URI 에 추가

```
https://실제도메인/api/auth/callback/kakao
```

**네이버** — 애플리케이션 정보 → PC 웹 → Callback URL 에 추가

```
https://실제도메인/api/auth/callback/naver
```

> `localhost` 주소는 **지우지 마세요.** 개발·테스트할 때 계속 사용합니다.
> 두 주소를 함께 등록해 두면 개발과 실서비스가 동시에 동작합니다.

# 자주 나는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 버튼을 눌렀더니 `KOE006` 또는 `redirect_uri mismatch` | Redirect URI 오타. 끝에 `/`를 붙이거나 `https`로 잘못 쓴 경우가 많습니다. 위 주소와 글자 단위로 대조해 주세요. |
| 카카오 로그인 시 `KOE010` / 인증 실패 | 1-5단계의 **Client Secret 활성화 상태**가 '사용안함'입니다. '사용함'으로 바꿔 주세요. |
| 네이버 로그인 후 빈 화면 | Callback URL 에 `/api/auth/callback/naver` 경로가 빠졌습니다. |
| 설정을 다 했는데도 버튼이 안 보임 | 서버 재시작을 안 한 경우입니다. `.env` 변경은 재시작해야 반영됩니다. |
| 앱 키를 잃어버림 | 카카오·네이버 개발자 사이트에서 언제든 다시 확인·재발급할 수 있습니다. |

# 담당자용 메모

전달받은 값을 `ujk` 프로젝트 루트의 `.env` 파일에 아래와 같이 기록합니다.

```env
AUTH_KAKAO_ID="카카오 REST API 키"
AUTH_KAKAO_SECRET="카카오 Client Secret"
AUTH_NAVER_ID="네이버 Client ID"
AUTH_NAVER_SECRET="네이버 Client Secret"
```

저장 후 개발 서버를 재시작합니다.

```bash
npm run dev
```

`src/auth.config.ts` 의 `socialEnabled` 가 네 값의 존재 여부를 보고
자동으로 로그인 제공자를 켜므로, 코드 수정은 필요하지 않습니다.

> `.env` 는 `.gitignore` 에 포함되어 있어 git 에 올라가지 않습니다.
> 실서버 배포 시에는 호스팅 서비스의 환경변수 설정에 같은 값을 넣어 주세요.
